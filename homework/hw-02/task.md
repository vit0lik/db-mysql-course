# ДЗ №2: создание своей таблицы

## Задание

1. Составьте список песен, фильмов, книг или прочих сущностей
   (согласно своим предпочтениям). Только один список для одной таблицы.
2. Для каждого элемента списка подберите подходящие свойства.
3. Преобразуйте список в таблицу: создайте таблицу, используя разнообразные
   типы полей, заполните таблицу данными из своего списка.
