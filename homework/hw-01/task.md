# ДЗ №1: SELECT — выборка данных

## Подготовительный этап

1. Установите сервер MySQL и/или настройте доступ к БД через хостинг.
2. Скачайте лабораторный SQL-файл: [clients.sql](clients.sql).
3. Исполните (импортируйте) его в свою базу данных:

   ```bash
   mysql -u <user> -p <database> < clients.sql
   ```

## Задание

Составьте следующие запросы и проверьте их на практике.

1. Для поиска по каждому из имён:
   - а) Robert,
   - б) Jeffrey,
   - в) John,
   - г) Richard,
   - д) David,
   - е) по всем этим значениям в одном запросе.
2. Для выборки всех:
   - а) женщин,
   - б) мужчин.
3. Для определения имени и телефона среди всех клиентов с фамилией:
   - а) Williams,
   - б) Jones,
   - в) Brown,
   - г) Miller,
   - д) по всем этим значениям в одном запросе.
4. Для определения даты рождения и пола пользователей с именем или фамилией
   (то есть нужно найти всех пользователей, у которых либо имя, либо фамилия
   соответствуют заданным):
   - а) Kelly,
   - б) Thomas,
   - в) Clark,
   - г) Joseph.
5. Для определения пола, даты рождения и номера телефона пользователей
   с именем и фамилией:
   - а) Tom Brown,
   - б) Janet Silberstein,
   - в) John Foster.

Текст SQL-запросов сохраните в файл и прикрепите его в отклик.
