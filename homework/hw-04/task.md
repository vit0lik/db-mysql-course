# ДЗ №4: приведение таблицы к нормальной форме

## Задание

Дана таблица:

```
Пациент (КодПациента, ФиоПациента, КодВрача, ФиоВрача, ДатаПосещения)
```

Пациент может посещать нескольких врачей, причем многократно, но конкретного врача не более раза в день

Нужно:

1. создать исходную таблицу на SQL;
2. заполнить её данными через `INSERT INTO`;
3. привести таблицу к нормальной форме: создать новые таблицы
   (`CREATE TABLE`) и/или изменить исходную (`ALTER TABLE`), по возможности
   сохранив данные в начальной таблице;
4. в нескольких предложениях объяснить изменения.

## Суть изменений

В исходную таблицу добавил один дубликат, который никак не проверялся и не подходил по правилу (Пациент может посещать нескольких врачей, причем многократно, но конкретного врача не более раза в день).  

Создал 3 таблицы `patients`, `doctors`, `visits`, чтобы убрать дублирование имен пациентов и врачей, контролировать уникальность визитов. В `visits` составной первичный ключ `(patient_id, doctor_id, visit_date)`, который задаёт уникальность визита и выражает правило
из задания.

Исходная таблица `visits_raw` остаётся в базе, по ней можно сверить данные.
