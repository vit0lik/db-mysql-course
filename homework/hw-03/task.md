# ДЗ №3: обновление и удаление данных

## Часть 1. Таблица clients

Составьте запросы на обновление данных в таблице клиентов ([clients.sql](../hw-01/clients.sql)):

1. Найдите клиентов Gary Harrison, Michael Atwood, Amy Majors, Katherine Smith
   и обновите дату их рождения до 21.10.1930, 12.04.1934, 01.08.1975,
   22.09.1959 соответственно.
2. Найдите клиентов с годом рождения ранее 1933 года и удалите номер телефона.
3. Исправьте ошибку клиента John Ohara, его настоящее имя Johanna Ohara,
   не забудьте поправить и пол клиента.
4. Замените номера телефонов Humberto Hoosier, Irene Schreiber, Donna Wallace
   на произвольные значения (для каждого свои).
5. Удалите клиентов с ID 215, 340, 449, 470, 607.
6. Удалите клиентов мужского пола с датой рождения в период с 01.01.1941
   по 30.04.1941 и с 10.09.1972 по 15.09.1972.

## Часть 2. Своя таблица из ДЗ №2

Произведите обновление данных в своей таблице из предыдущего задания.
Не менее 5 запросов.

По каждому из запросов предварительно найдите записи, подлежащие обновлению,
запишите количество таких записей. Используйте `LIMIT` для каждого запроса
на обновление.

По завершении каждого запроса запишите количество обновлённых строк.
