# ДЗ №5: строковые функции и поиск по шаблону

## Задание

1. Сделайте выборку `id` и имён клиентов, приведённых:
   - а) к верхнему регистру;
   - б) к нижнему регистру.

2. Выведите по каждому клиенту фамилию и имя в одном столбце, а в другом —
   номер телефона в сокращённом виде: первые три и последнюю одну цифру
   в открытом виде, остальные символы закрыть знаком `x`, `*` или `#`
   (например: `977***4`).

   Первому столбцу дайте имя `full_name`, второму — `phone_number`.

3. Выведите по каждому клиенту, в фамилии которого есть такие вхождения
   строк `tt`, `ss`, `ll`, имя и фамилию в формате, где имя сокращено
   до 1 символа с точкой (например: `J. Williams`).

4. Найдите все записи, в которых телефонные номера:
   - а) начинаются на `586`;
   - б) содержат `657`;
   - в) заканчиваются на `707`.

   Составьте запросы из всех возможных вариантов поиска таких подстрок.
